Hill Rush - physics-based hill climb driving game
==================================================

Play right away:
    ./hillrush

Install for your user (adds a menu entry, no root needed):
    ./install.sh

Uninstall:
    ./uninstall.sh

Controls
    Right / D ......... gas          Left / A ...... brake / reverse
    Esc / P ........... pause        R ............. restart
    F11 ............... fullscreen   F12 ........... screenshot
    Gamepads work too (A / right trigger = gas, X / left trigger = brake),
    and you can click or touch the pedals on screen.

Your progress is saved in ~/.local/share/hillrush/save.txt.
Run ./hillrush --help for command line options.
